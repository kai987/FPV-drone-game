# AEROFLOW · FPV Drone Game

可直接在浏览器中玩的无人机飞行与投弹游戏，支持第一视角、追尾视角和俯视瞄准。React、TypeScript、Vite 和 Three.js 负责界面与三维场景，Rust 编译为 WebAssembly，运行飞行、风场、地理查询、投弹及场景/动画的批量数值计算。无需账号或后端。

## 本地运行

开发与构建需要 Node.js 22.18+（建议 Node.js 24）、npm，以及通过 rustup 管理的 Rust/Cargo。仓库的 `rust-toolchain.toml` 固定 **Rust 1.93.0** 和 **`wasm32-unknown-unknown`** 目标；首次使用时，rustup 会按配置准备对应工具链和目标。

网页玩家只需支持 WebGL 2 和 WebAssembly 的浏览器，不需要安装 Node.js 或 Rust。

```sh
npm ci
npm run dev
```

打开终端给出的地址，默认是 http://127.0.0.1:5173/ 。

```sh
npm run build:wasm # 单独编译 Rust 并更新 WASM 产物
npm test           # 编译 WASM，运行 Cargo 原生测试与 Node 测试
npm run check      # npm test，再运行 TypeScript 检查
npm run build      # 编译 WASM、检查 TypeScript，生成 dist/ 静态网站
npm run preview    # 预览已有的 dist/ 生产构建
```

`npm run dev`、`npm test`、`npm run check` 和 `npm run build` 都会先构建 WASM。开发服务器目前不监听 Rust 源码：修改 Rust 后需执行 `npm run build:wasm`，或重启 `npm run dev`。`src/game/generated/flight_core.wasm` 与 Cargo 的 `target/` 目录是构建产物，已加入 Git 忽略规则；全新检出会通过上述脚本生成。

`dist/` 可部署到任意静态网站服务。构建采用相对资源路径，支持子目录。仓库 CI 对每次推送和 PR 运行检查与构建。无付费 API、服务器密钥或数据库依赖。

## GitHub Pages 发布

线上地址：[AEROFLOW 飞行场](https://kai987.github.io/FPV-drone-game/)。

仓库 **Settings → Pages → Build and deployment → Source** 设为 **GitHub Actions**。发布由 [pages.yml](./.github/workflows/pages.yml) 完成：推送到 `main` 后，安装 Node.js 24 与 Rust 1.93.0 的 WASM 目标，执行 `npm ci`、`npm run check`、`npm run build`，将 **`dist/`** 上传为 Pages artifact，再部署到 `github-pages` 环境。检查或构建失败时不会发布。

也可在 **Actions → Deploy game to GitHub Pages → Run workflow** 选择 `main` 手动重新发布。其他分支不发布；PR 使用独立 CI 检查。`dist/` 与生成的 WASM 不提交 Git，线上只接收构建后的 HTML、JavaScript、CSS、WASM 和美术资源。当前 `base: './'` 保证资源在 `/FPV-drone-game/` 子目录及本地预览中正常加载。

发布后应确认 Actions 中的 `build` 和 `deploy` 都成功，再打开线上地址检查游戏加载与起飞；一次普通 CI 构建成功并不表示网页已更新。发布流程参考 [GitHub 自定义 Pages 工作流](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。

## 游戏内容

- **FPV 机库**：涵道航拍、花式穿越、竞速、远航及两款极速原型，共六款游戏机型，机库缩略图直接渲染游戏同款三维模型，选中后可拖动旋转查看细节，并查看硬件参考规格和实际飞行性能；不同机型具有不同机架外形、速度、爬升、转向及加减速响应。
- **松林山谷**：3.6 × 3.6 公里（约 13 km²）可飞行区域，包含平滑起伏地形、成片松林、草甸、岸边岩石与 8 个飞行环；飞行高度上限 450 米。
- **工业工厂**：独立八环航线穿过工业大道、波纹金属厂房、储罐、砖烟囱、架空管道和货车；可从管道下方飞过，也可降落在厂房屋顶。
- **海港码头**：海岸与三个混凝土码头、彩色集装箱堆场、门式吊机与悬挂货物、货轮、灯塔和防波堤；海面有动态波纹、反光与岸边浪花，夜间灯塔有旋转光束。
- **地图切换**：首次进入会准备三张地图的场景、纹理及物理服务，并显示逐图进度；全部准备完成后即可起飞。左侧「山谷 / 工厂 / 海港」直接切换已缓存场景，返回所选地图起点并重置航线、计时和投弹；保留机型、游戏/飞行模式、风况、昼夜、声音与视角。每图都有对应小地图、8 个检查点和 5 个练习靶标。
- **工业道路**：工厂与海港各有三处十字路口，四个方向均设有斑马线与停止线，车道标线和路缘在路口处留出通行空间；小地图共用道路布局，放大后显示斑马线。
- **河流与湖泊**：蜿蜒河道连接翡翠湖、松影湖，具有不规则湖岸、浅水渐变、三层动态细波纹、沿河道的纹理流动和天空远山倒影；树林与岩石避开水域，沿岸分布灌木与砾石。
- **乡间生活**：三间带门窗、烟囱与木梁的小屋，一座连接两岸的木桥；牧场里的牛羊会缓步行走、低头吃草，河湖内的鱼群会结伴游动摆尾。小地图标出小屋、桥和鱼群的位置。
- **夜间模式**：点击页头「日间 / 夜间」或按 N，随时切换月光、星空、亮窗和无人机探照灯，保留飞行位置、计时及弹药。
- **岩石细节**：新增风化岩面贴图，以三向投影显示矿物颗粒、裂隙和苔痕，并模拟细小表面起伏。
- **计时挑战**：按顺序从正面穿过亮色环，完成后显示成绩，并按地图、机型、飞行模式和风况保存个人最佳。
- **自由飞行**：在当前地图内探索，无穿环要求与碰撞计时惩罚。
- **辅助模式**：快速刹车、稳定悬停；**运动模式**：更快速度、更大惯性和倾斜反馈。
- **碰撞反馈**：撞到树干、岩石或地面会减速，挑战模式增加 3 秒。持续接触有惩罚冷却。
- **风况模拟**：无风、微风、中等风、强风与八个来风方向；平滑阵风随时间、位置和高度变化，迎风、顺风与侧风实际改变地速、航迹和机身倾斜。辅助模式减轻风偏，运动模式需要更主动修正；画面左上角可查看和调整风况，小地图左侧罗盘的箭头实时显示风吹向，附带来风名称；无风时显示圆点。
- 实时地速、高度、飞行时间、检查点、目标距离；带实际水域轮廓的小地图支持「航线 / 全域」切换，自由飞行默认全域地图；「− / +」切换 1× / 2× / 4× / 8×，放大后跟随无人机；鼠标/触摸拖动或方向键平移进入自由浏览，点击「跟随」或 Home 回到无人机；点击倍率或地图预设恢复 1× 总览。
- **投弹练习**：6 枚炸弹，投完后 3 秒自动补充；炸弹继承飞行速度并下落，触地依次呈现短促闪光、火团、飞散尘土与持续扩散的烟雾；触水则产生飞溅和涟漪。5 个地面靶标每个首次命中得 100 分，小地图橙色菱形标出位置。
- 默认追尾视角显示完整四旋翼无人机、动态螺旋桨、指示灯和飞行倾斜；按 V 或点击画面右上角依次切换追尾 → 俯视瞄准 → 第一视角。
- 暂停/继续、重新起飞、全屏、可选电机、穿环与投弹音效，以及手机多点触屏操作。

两种模式在无风时均自动维持悬停，有风时会产生漂移，需要主动修正。这是易上手的飞行模型，运动模式也不是专业 Acro/Rate 或重力飞行模拟器。

## 操作

| 操作 | 按键 |
| --- | --- |
| 向前 / 向后 | W / S |
| 左右平移 | A / D |
| 左右转向 | Q / E，或左右方向键 |
| 上升 / 下降 | Space / Shift |
| 抬头 / 低头 | 上下方向键 |
| 暂停 | Esc |
| 暂停 / 继续 | P |
| 从起点重新起飞 | R |
| 投弹 | B，或画面内「投弹」按钮 |
| 日间 / 夜间 | N，或页头昼夜按钮 |
| 追尾 / 俯视瞄准 / 第一视角 | V，或画面右上角视角按钮 |

飞行时点击三维画面可启用鼠标视角。Esc 释放鼠标并暂停。切换页面或失去窗口焦点也会自动暂停。手机起飞后显示移动、转向及高度按钮，可同时按多个按钮。

无风时按 W 即可练习首两个飞行环；默认西北微风会产生轻微偏移，需要用 A/D 修正。之后根据亮色目标和小地图调整方向及高度。游戏与飞行模式在飞行和暂停期间锁定，返回起点后可以切换；风况可随时打开调整，打开时暂停，应用后保留位置并等待继续。

起点正下方有一个练习靶标：开始飞行后按 V 切换俯视瞄准，再按 B 即可练习投弹。移动中的炸弹会沿飞行方向继续运动，俯视准星表示机身下方，而非预测落点。两种游戏模式都能投弹，得分独立于穿环计时；暂停会冻结炸弹、爆炸和补充倒计时，重新起飞会恢复弹药、靶标与得分。

水面使用可平铺的程序化法线纹理：近处呈现细碎波峰，远处通过 mipmap 与屏幕像素尺度淡化细节。河面纹理随局部河道方向移动，湖面保留较缓的风纹；倒影采样现有天空全景，并随观察角度变化。

自由飞行中可沿河流探索两处湖泊和远处山坡；小地图切换「全域」后可查看完整地理位置。无人机接触水面会稳住机身，投弹触水产生浅色水花与涟漪。碰撞与镜头都使用地面或水面高度，避免穿入水下。

观察鱼群：切换「航线」地图，寻找浅蓝鱼形标记。起点东侧河湾和木桥下游都有鱼群，靠近后在水面上方约 2–8 米悬停，按 V 切到俯视更容易看清。全域地图还标出了两处湖泊中的鱼群；高空或贴近水平的视角会受到水面反光影响。

打开「机库」可浏览六款无人机的三维外形和各项参数，并选择起飞机型。卡片图片、大图与飞行场共用同一模型；大图支持拖动旋转、滚轮或双指缩放，点击「复位」恢复完整视角。橙、绿、红、蓝、青、金六种配色用于区分机型，模型包含碳板、电子堆叠、电池绑带、倾角相机、电机、旋翼与天线等细节。飞行途中查看机库会暂停游戏；更换机型需返回起点，界面提供明确的「返回起点并应用」操作。机型为游戏内虚构配置，硬件和续航是参考设定，不模拟真实电池耗电；界面中飞行速度等性能由实际飞行配置计算。

新增 **VECTOR 矢量**（运动模式 260 km/h）与 **FALCON 游隼**（360 km/h），具有不同的高速机架；FALCON 采用火箭般的长中央舱和四个平行电机舱，悬停时主轴直立，加速前进时向航向倾斜。灵感分别来自 [DRL RacerX 的 2017 年 163.5 mph 纪录（约 263 km/h）](https://www.guinnessworldrecords.com/news/commercial/2017/7/the-drone-racing-league-builds-the-worlds-fastest-racing-drone-482701) 和 [AirShaper 记载的 Peregreen V4 平均纪录约 657 km/h](https://airshaper.com/cases/peregreen-v4-fastest-drone)。机库分别显示原型纪录与无风游戏限速；这些是游戏改编机型，硬件参数不是原型实测配置。切换到「运动」飞行模式后才使用对应的更高限速。

个人成绩按地图、机型、飞行模式、风力与来风方向分别保存在当前浏览器的 localStorage 中；原山谷成绩键保留，新地图使用含地图标识的独立记录，不读取山谷旧成绩。旧版成绩仅归入山谷对应机型的无风条件，更旧的记录归入山谷 FLOW 无风条件。飞行中改变风况的该轮不计入个人最佳，重新开始可正常记录；禁用本地存储仍可飞行。默认静音，声音须手动开启。运行需要 WebAssembly、WebGL 2 和硬件加速，不支持时显示可读提示。

## 结构与验证

Rust 负责飞行与风场、地面/河湖/桥面/屋顶查询、障碍空间网格、投弹弹道和计分/装填，以及场景布局、水纹生成、鱼群/牛羊动画与爆炸粒子的批量计算。TypeScript 保留输入、共享场景和机型配置、穿环、计时、音效、界面与 Three.js 渲染。飞行和炸弹直接使用同一 Rust 世界，没有生产地形/障碍回调。

一个游戏共享一个 WASM 实例；每类服务拥有独立缓冲和生命周期，适配器在内存增长后重新取得视图。每个活动飞行帧通过一次 `simulate_world_tick` 完成飞行与风场，武器、鱼群、牛羊和爆炸各自一次批量更新，直接向 Three.js 复制矩阵或粒子属性。场景初始化整批生成原有种子下的树林、岩石、岸边植被、地形颜色、河流流向和水纹纹理。加载器缓存编译后的 `WebAssembly.Module`，各游戏实例的内存仍独立；销毁时先释放各服务，最后释放共享世界。

工厂与海港的建筑、货物及高架结构由同一份米制布局驱动渲染、小地图和 Rust 实体盒碰撞，旋转箱体使用真实矩形轮廓。原生世界按地图查询平地、海岸与码头，以及上一帧高度能够抵达的屋顶/甲板；炸弹从上方落到建筑顶面，从高架下方落到较低地面。新增地图采用独立的程序云天与海面 GPU 着色器，跳过山谷植被和动物生成。首次进入会缓存三张完整地图、等待外部纹理并预编译着色器和预热 GPU；三张地图共用一个 WebGL 上下文、一套输入监听和一个 WASM 实例，各自持有独立的世界、飞行及武器服务。切图直接复用缓存并重置飞行，离开游戏时统一释放所有地图资源。

原 TypeScript 数学函数、无 runtime 的模型构造路径及冻结的旧场景/爆炸方程保留为独立测试参考，游戏始终提供 Rust 服务。GPU 上的水面、烟火、植被着色器和 Three.js 模型材质继续使用现有实现。本轮不增加 Worker 或声称帧率提升；WASM 数值计算仍同步运行，提速需要单独测量。

## 美术与许可

远山与云层采用参考图的雪峰、松林山谷和蓝天白云风格，由内置 Image Gen 生成1774×887图像，再经Real-ESRGAN的4倍超分辨率处理，提供7096×3548的高清WebP及3548×1774的手机版，按实际画面宽度和GPU能力自动选择。这是超分辨率增强素材，不能视为原生7K/8K摄影；河湖反射共用此全景。背景树木位于地平线以下，并平滑过渡为雾色，保持地图树林的比例。透明松树、草地与风化岩石纹理也由内置 Image Gen 生成，已随仓库提供。生成提示词、处理方式与素材来源见 [asset-licenses.md](./docs/asset-licenses.md)。松树用实例化交叉贴图节省 GPU 开销，地形和飞行环是原生三维几何体。HUD 与所有操作控件使用 HTML/SVG。字体为 Manrope / Noto Sans SC，可用时从 Google Fonts 加载，离线时回退到系统字体；图标使用 Lucide。
