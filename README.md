# AEROFLOW · FPV Drone Game

可直接在浏览器中玩的无人机飞行与投弹游戏，支持第一视角、追尾视角和俯视瞄准。使用 React、TypeScript、Vite 和 Three.js 构建，无需账号或后端。

## 本地运行

需要 Node.js 22.18+（建议 Node.js 24）和 npm。

```sh
npm ci
npm run dev
```

打开终端给出的地址，默认是 http://127.0.0.1:5173/ 。

```sh
npm run check     # TypeScript 检查和物理/赛道测试
npm run build     # 生成 dist/ 静态网站
npm run preview   # 预览生产构建
```

`dist/` 可部署到任意静态网站服务。构建采用相对资源路径，支持子目录。仓库 CI 对每次推送和 PR 运行检查与构建。无付费 API、服务器密钥或数据库依赖。

## 游戏内容

- **松林山谷**：3.6 × 3.6 公里（约 13 km²）可飞行区域，包含平滑起伏地形、成片松林、草甸、岸边岩石与 8 个飞行环；飞行高度上限 450 米。
- **河流与湖泊**：蜿蜒河道连接翡翠湖、松影湖，具有不规则湖岸、浅水渐变、三层动态细波纹、沿河道的纹理流动和天空远山倒影；树林与岩石避开水域，沿岸分布灌木与砾石。
- **乡间生活**：三间带门窗、烟囱与木梁的小屋，一座连接两岸的木桥；牧场里的牛羊会缓步行走、低头吃草，河湖内的鱼群会游动摆尾。小地图标出小屋和桥的位置。
- **夜间模式**：点击页头「日间 / 夜间」或按 N，随时切换月光、星空、亮窗和无人机探照灯，保留飞行位置、计时及弹药。
- **岩石细节**：新增风化岩面贴图，以三向投影显示矿物颗粒、裂隙和苔痕，并模拟细小表面起伏。
- **计时挑战**：按顺序从正面穿过亮色环，完成后显示成绩，并按飞行模式保存个人最佳。
- **自由飞行**：在有边界的山谷里探索，无穿环要求与碰撞计时惩罚。
- **辅助模式**：快速刹车、稳定悬停；**运动模式**：更快速度、更大惯性和倾斜反馈。
- **碰撞反馈**：撞到树干、岩石或地面会减速，挑战模式增加 3 秒。持续接触有惩罚冷却。
- 实时速度、高度、飞行时间、检查点、目标距离；带实际水域轮廓的小地图支持「航线 / 全域」切换，自由飞行默认全域地图。
- **投弹练习**：6 枚炸弹，投完后 3 秒自动补充；炸弹继承飞行速度并下落，触地依次呈现短促闪光、火团、飞散尘土与持续扩散的烟雾；触水则产生飞溅和涟漪。5 个地面靶标每个首次命中得 100 分，小地图橙色菱形标出位置。
- 默认追尾视角显示完整四旋翼无人机、动态螺旋桨、指示灯和飞行倾斜；按 V 或点击画面右上角依次切换追尾 → 俯视瞄准 → 第一视角。
- 暂停/继续、重新起飞、全屏、可选电机、穿环与投弹音效，以及手机多点触屏操作。

两种模式均自动维持悬停。这是易上手的飞行模型，运动模式也不是专业 Acro/Rate 或重力飞行模拟器。

## 操作

| 操作 | 按键 |
| --- | --- |
| 向前 / 向后 | W / S |
| 左右平移 | A / D |
| 左右转向 | Q / E，或左右方向键 |
| 上升 / 下降 | Space / Shift |
| 抬头 / 低头 | 上下方向键 |
| 暂停 | Esc |
| 暂停 / 继续 | P |
| 从起点重新起飞 | R |
| 投弹 | B，或画面内「投弹」按钮 |
| 日间 / 夜间 | N，或页头昼夜按钮 |
| 追尾 / 俯视瞄准 / 第一视角 | V，或画面右上角视角按钮 |

飞行时点击三维画面可启用鼠标视角。Esc 释放鼠标并暂停。切换页面或失去窗口焦点也会自动暂停。手机起飞后显示移动、转向及高度按钮，可同时按多个按钮。

按 W 即可练习首两个飞行环。之后根据亮色目标和小地图调整方向及高度。设置在飞行和暂停期间锁定，返回起点后可以切换。

起点正下方有一个练习靶标：开始飞行后按 V 切换俯视瞄准，再按 B 即可练习投弹。移动中的炸弹会沿飞行方向继续运动，俯视准星表示机身下方，而非预测落点。两种游戏模式都能投弹，得分独立于穿环计时；暂停会冻结炸弹、爆炸和补充倒计时，重新起飞会恢复弹药、靶标与得分。

水面使用可平铺的程序化法线纹理：近处呈现细碎波峰，远处通过 mipmap 与屏幕像素尺度淡化细节。河面纹理随局部河道方向移动，湖面保留较缓的风纹；倒影采样现有天空全景，并随观察角度变化。

自由飞行中可沿河流探索两处湖泊和远处山坡；小地图切换「全域」后可查看完整地理位置。无人机接触水面会稳住机身，投弹触水产生浅色水花与涟漪。碰撞与镜头都使用地面或水面高度，避免穿入水下。

个人成绩只保存在当前浏览器的 localStorage 中；禁用本地存储仍可飞行。默认静音，声音须手动开启。三维场景需要 WebGL 2 和硬件加速，不支持时显示可读提示。

```text
src/App.tsx                  页面与游戏状态

src/game/flight.ts           独立飞行物理与穿环检测
src/game/engine.ts           帧循环、输入、碰撞与挑战流程
src/game/drone.ts            可见四旋翼机身与螺旋桨动画
src/game/weapons.ts          投弹、弹药、地面命中与得分模拟
src/game/weapon-visuals.ts   地面靶标、炸弹与爆炸三维效果
src/game/world.ts            山谷、检查点和实例化场景
src/game/landscape.ts        扩展地图边界、河湖轮廓与连续地形高度
src/game/water.ts            多尺度水纹、河道流动、浅水细节与天空反射
src/game/rural-layout.ts     小屋、桥梁、牧场与鱼群路径的共享地理布局
src/game/rural.ts            乡村模型、牛羊与游鱼动画、窗灯
src/game/night-sky.ts        月亮与星空
src/game/rock-material.ts    岩石三向纹理与表面起伏
src/game/surfaces.ts         可从桥下通过的建筑/桥面支撑高度
src/game/collisions.ts       斜屋顶与桥下净空的障碍碰撞
src/game/audio.ts            Web Audio 电机、穿环与投弹音效
public/assets/               随仓库提供的游戏美术
tests/                      飞行物理、完整赛道、投弹与地理测试
docs/design.md              设计、素材与视觉验证说明
```

测试覆盖不同帧率的稳定性、惯性、转向/视角移动、地形接触、高速穿环与方向检查，并用正常控制完成两种模式的真实 8 环赛道，没有通过传送跳过飞行过程。

地理测试还覆盖河湖连通、岸线与地形一致性、连续高度、扩大后的边界、原有起点/检查点/靶标安全性，以及无人机与炸弹在水面接触。实际浏览器验证包含越过旧地图边界、抵达湖泊、地图范围切换和触水保护。

当前 38 项测试还包括桥面着陆、桥下飞行与投弹、斜屋顶落点，以及实际动画中牛羊与鱼群始终位于安全草地和水域。乡村模型、昼夜切换、两种爆炸效果与手机短屏在生产构建中实测检查。

## 美术与许可

山脉、透明松树、草地与风化岩石纹理由内置 Image Gen 生成，已随仓库提供。松树用实例化交叉贴图节省 GPU 开销，地形和飞行环是原生三维几何体。HUD 与所有操作控件使用 HTML/SVG。字体为 Manrope / Noto Sans SC，可用时从 Google Fonts 加载，离线时回退到系统字体；图标使用 Lucide。
