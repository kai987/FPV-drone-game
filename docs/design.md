## 有意采用的三维实现

概念画面的前景采用实时地形、道路、岩石和飞行环，以支持第一视角的自由移动、惯性与碰撞，无法与固定摄影式参考逐像素一致。松树为带透明纹理的交叉面片，使手机也能渲染较大的松林；山脉是远景天空球。碰撞、积分、计时、HUD、地图、检查点编号均由代码实现。

首屏保留参考的信息结构、布局、颜色、主标题和 CTA，场景构图会随飞行实时改变。声音按钮默认静音；这是避免未经点击的浏览器音频播放所需的状态差异。

## 可见无人机追加要求

根据用户要求“想要看到无人机”，新增默认追尾视角和原生三维四旋翼模型。机身、支臂、电机、螺旋桨和指示灯采用真实三维几何，随玩家位置、转向、俯仰和倾斜更新；螺旋桨在飞行时加速旋转。该几何模型用于自由视角和动画，是用户追加要求下的有意视觉扩展。

原 FPV 标记改为可点击视角切换按钮，新增 V 快捷键及指南说明。追尾镜头保持稳定的地平线，并有平滑跟随和地面避让；切换第一视角隐藏机身，保留原有 FPV 操作。切换视角不重置时间、检查点或飞行状态。

追加验收：生产构建通过，原 11 项测试全部通过。内置浏览器在 1536×1024 和 390×844 中确认机身可见，第一视角正确隐藏机身；用手机方向按钮实际飞过首环后，按 V 切换视角，进度保持 `01 / 08`，计时继续增长。最终控制台没有相关错误，左栏仍完整显示操作提示。最终浏览器截图通过 `view_image` 检查。

## 投弹系统追加要求

根据用户要求“加上武器系统，无人机可以投弹”，增加 B 键与触屏投弹按钮、6 枚弹药与 3 秒自动装填、5 个橙色地面靶标、每个靶标首次命中 100 分，以及原生三维弹体和短暂爆炸效果。模型采用游戏内简化重力与范围判定，与飞行控制同一帧循环运行。暂停冻结投弹模拟，重新起飞恢复弹药、靶标与得分。

武器 HUD 沿用小地图的森林色半透明面板与青柠按钮，手机上放在方向键上方。小地图使用橙色菱形标记靶标，命中后变为青柠色。V 按追尾、俯视瞄准、第一视角循环；俯视镜头同时保留可见机身与地面落点，解决常规追尾镜头看不到机身下方的问题。准星指向机身下方，移动投弹仍会继承机身速度。

炸弹、地面靶标、烟尘和冲击波均使用代码生成的真实三维几何，以支持下落、地形碰撞、视角切换和动画。这是用户追加游戏功能下的有意视觉扩展，保留现有生成场景素材与页面设计。

追加验收：22 项测试（含 11 项投弹测试）与生产构建通过。内置浏览器验证 B 键及触屏投弹、弹药减少、爆炸冲击环、命中变色与 +100 分、重复命中不重复计分、6 枚耗尽后自动补满、暂停时禁止投弹且冻结装填、返回起点恢复靶标和得分。计时挑战和自由飞行均实际命中；三个视角可切换，手机方向控制仍可前进。1536×1024、390×844、390×700、390×600 截图经直接查看，手机无横向或纵向溢出。短屏采用压缩设置区，并将武器面板放在左侧方向键上方，避免挡住准星、通知或小地图。最终生产页面控制台无警告或错误。

地形使用连续的低地、缓坡与山脊，河床和湖盆从地形中实际挖出。蜿蜒河道连接不规则的翡翠湖、松影湖；水面具有随深度变化的青绿色、浅滩、动态细纹与柔和反光。5200 棵松树形成疏密变化的林地，配合开阔草甸、粗糙岩石、岸边砾石和低矮灌木。沿用现有生成的草地、松树与远山素材，新增地形和水面由原生三维几何及着色器构成，以适应自由飞行视角。

小地图直接复用河湖轮廓，支持「航线 / 全域」切换并维持 X/Z 等比例；航线范围外显示提示，避免把远处的无人机误显示在旧赛道边缘。全域模式覆盖实际可飞行边界。飞行器、投弹和镜头统一使用地面/水面高度；落水爆炸改为浅色水花与涟漪。新增树林碰撞按空间网格查询，阴影随无人机移动，原有 8 环赛道与 5 个靶标仍处于干燥、安全的区域。

## 水波纹理细化

根据用户追加要求，水面从两组简单正弦细纹改为三层程序化波纹法线。256×256 可平铺纹理由固定种子的 48 组整数频率波叠加生成，分别覆盖较宽风纹、中等波峰和近景细波；使用 mipmap、各向异性过滤和屏幕像素尺度淡出减轻远景混叠。纹理在初始化时生成并在场景销毁时释放，无新增图片下载或渲染通道。

河道流向在初始化时由现有中心线计算为顶点属性，进入湖区后平滑减弱；双相位交叉平流避免弯道纹理随着时间持续拉伸。浅水增加低强度的动态光纹及零散岸边水沫，深水保留更沉的蓝绿色。反射复用已有远山天空全景，与波纹法线和视角共同变化；这是环境反射近似，不是附近物体的实时平面反射或流体模拟。地形、水平水位及游戏碰撞规则保持一致，非水区域的片元被裁切。

生产构建通过，28 项原有测试通过。内置浏览器实飞至河面及翡翠湖，在 12m 河面近景与 75m 湖面视角检查动态水纹、岸线、追尾/俯视/第一视角，并验证投弹扣减弹药。1536×1024 和 390×844 截图直接检查，手机页面无溢出，控制台无警告或错误。针对第一版近景过大的白色亮斑和过强浅水光纹，缩小波峰尺度并降低强度。真实手机 GPU 性能及其他浏览器尚未单独测试。

## 牛羊、灌木与鱼群可见度细化

针对牛羊模型与灌木偏简化、鱼群难以发现的反馈，牛羊、灌丛、鱼群分别拆为独立模块。保留原生三维模型以便低空绕飞观察；细节直接受现有日夜光照影响。灌木以弯曲木枝、依枝成簇的尖椭圆曲面叶替换绿色球体，叶脉、背面色差和轻微风动通过着色器表现；420 株较丰满灌丛上限约 64 万叶片三角形，分为枝条、主体叶片与稀疏投影叶片三个实例批次。

原鱼群在少数区域分散环游，且鱼体较小、水面透明度与反光遮盖较强，导致高空尤其难以识别。新增起点东侧河湾鱼群，并将 5 处水域的 82 条鱼改成相邻成排的紧密鱼群；鱼体增加背腹色差、鱼鳃、背鳍及摆尾。排距按路径实际长度换算，以免小河湾内鱼身挤成一团。浅水增加透光，保留随视角增强的反射。地图新增浅蓝鱼形位置标记，指南说明低空悬停与俯视观察方法；无需透视或调试传送。

牛羊使用连续截面生成躯干、颈部和头部，补充口鼻、耳眼、牛角、关节与分趾蹄。奶牛增加自然斑纹及细毛起伏，羊毛由细密表面起伏和小卷毛共同表现；保留走动、低头吃草和摆尾。浅水河床改为砂石色与岩纹，避免透过水面看到草地纹理。

## Rust 飞行物理与风场迁移

按用户要求，先将飞行物理与风场迁入 `rust/flight-core`，编译为浏览器 WebAssembly。每个飞行帧由一次 Rust 调用统一推进位置、速度、偏航、俯仰、侧倾与风场时钟，并返回实际风向、风速及迎顺侧风遥测。保留原有辅助/运动模式、六机型共享参数、阵风公式和最长 0.06 秒步长，使用 f64 保持迁移前后的数值一致。Three.js 使用返回状态更新机身、旋翼、相机和画面；输入、穿环、投弹、成绩、音效与界面继续由现有 TypeScript 模块管理。

投弹状态由 Rust 持久持有，包含弹药、冷却、装填、活动炸弹、爆炸、目标首次命中及得分。一次调用推进全部弹体，保留四段轨迹采样、18 次二分定位落点、重力、继承地速、容量上限和原时间步策略。固定 51 个输入及 386 个输出数值，返回全部状态和命中事件；声音、通知、目标变色和 DOM 仪表仍由界面层管理。

鱼群一次输出全部身体、鱼尾、鳍、眼睛和鱼鳃矩阵；牛羊一次计算活动状态、吃草、行走、头颈尾、关节、蹄及羊毛等所有部件矩阵，地面高度直接使用 Rust 世界。爆炸一次输出六类粒子、冲击环、碎屑和固定三盏闪光灯的矩阵、颜色、透明度与种子，包含陆地、水面和夜间条件。输出整块复制至 Three.js 属性，避免逐物体、逐骨骼或逐粒子调用 WASM。既有 GPU 水波、烟火噪声和植被风动保持现有着色器实现。

共享运行时负责导出调用、重入保护和内存边界检查；各服务拥有自己的句柄和固定缓冲，读取前重新获取视图以支持内存增长。销毁时先释放飞行、武器、特效、生态及渲染资源，最后释放共享世界。原 TS 数学与无 runtime 模型路径保留为独立测试参考，生产没有失败后切回 JS 数值计算的机制。WASM 仍同步运行在主线程，此轮未加入 Worker，也没有测量帧率改善。

## 远山与云层清晰度

按照用户参考图恢复灰色雪峰、松林山谷与蓝天白云的视觉风格。内置Image Gen的实际原始输出为1774×887，再用官方Real-ESRGAN通用图像模型4倍超分到7096×3548，WebP编码后约3.3MB；手机版缩为3548×1774，约1.3MB。超分改善放大后的岩层、雪缘与云丝细节，但不能视作原生7K/8K照片或等量的真实采样细节。生成提示词、工具版本、处理命令和SHA256详见asset-licenses.md。

当实际画面宽度（CSS宽度×渲染器像素比）超过900像素，且GPU最大纹理尺寸至少7096时，选用高清版；其余选用手机版。此选择在游戏初始化时确定，窗口缩放不会反复下载或重建纹理。采用SRGB、线性放大、带mipmap的线性缩小、最高8倍且受硬件限制的各向异性采样。水平重复、垂直夹取，保留天空球96×48细分和原像素比上限。生成图左右云形并非逐像素连续；共享GLSL采样函数在两端各1.5%（约5.4°）内平滑混合镜向边缘，接缝上的两端各占50%，过渡外保持原图。天空与水面共用此函数，避免背景与倒影的衔接方式不同。

采样导数在分支与水平UV折返之前计算，水平导数也按重复周期展开，使用WebGL2显式梯度选取mipmap；防止接缝处的1→0跳变错误选中最低细节层而产生竖线。附加镜向采样只发生在边带内。

天空旋转设为π/2，让默认前方显示图中主雪峰；旋转作为uniform同步河湖反射，避免背景与倒影角度不同。日夜仍使用同一全景和现有夜间颜色、星月与照明处理。旧摄影全景从当前资源中移除，历史版本可由Git恢复。

贴图加载完成前保留天空背景色，避免首帧黑色天空。生成图中森林都在地平线下方；天空与水面共用地平线过渡，仅呈现远山和天空。
